# ItrsscilogonAssigner

A COmanage Registry identifier assigner plugin for the ITRSS deployment. It gets each new ITRSS CO Person's CILogon user identifiers from the CILogon OA4MP dbService and stores them as OIDC sub Identifiers.

See the [reference documentation](docs/README.md) for what the plugin needs, how it works, how it is configured, how to check it, what its errors mean, and why it was built this way.
